# 《语法条校对稿.md》错误清单

&gt; 仅列出错误部分，按等级和条目编号排列。

---

## N5

### 第1条
- **注意**：`△妹はいもうと学生じゃせんではありません。会社員です。` → 应为 `△妹は学生じゃありません。会社員です。`（多出「いもうと」注音残留、「じゃせん」应为「じゃ」）

### 第2条
- **例句1**：`おとといはあめ雨で、昨日は雪き no u雪。` → 应为 `おとといは雨で、昨日は雪でした。`（注音残留、乱码）

### 第3条
- **例句2**：`小林さんは上海人ではありません。はやし` → 应为 `小林さんは上海人ではない。`（与条目「だ/ではない」普通体不一致，且注音残留）

### 第4条
- **例句1**：`3年前、あの人はこの会社のさんねんまえ社長ひつだった。` → 应为 `3年前、あの人はこの会社の社長だった。`（注音残留乱码）

### 第5条
- **例句1**：`A「あの人は山下ひたさんですか」` → 应为 `A「あの人は山下さんですか」`（注音残留）

### 第7条
- **例句3**：`今後に一緒にに遊びに行くとき` → 应为 `今度一緒に遊びに行くとき`（「今後」应为「今度」，多一「に」）

### 第10条
- **例句2**：`これからどうするのかわくりに考えなさい。` → 应为 `これからどうするのかよく考えなさい。`（乱码）

### 第11条
- **例句1**：`こちらの部屋です。【2002年真题】老师的房间在这里。` → 译文与例句不符，应为 `房间在这里。`

### 第12条
- **接续**：`こんな、そんな、あんな、どんな＋名词 こんな、そんな、あんな、どんな＋形容词/名词` → 重复，应删去后半

### 第19条
- **例句2**：`昨日の夜は6時に帰て、ご飯をしました。` → 应为 `帰って`（缺「っ」）

### 第23条
- **例句1**：`運動をしてもいいですか。【2006年真题】可以做运动了吗？` → 译文应为 `可以做运动吗？`

### 第41条
- **例句1**：`そのレストランの料理はどう いかがですか。` → 应为 `そのレストランの料理はどうですか。/いかがですか。`（排版错误）
- **例句2**：`紅茶をいっぱいいかが どうですか。` → 同上排版错误

### 第43条
- **注意**：格助词说明段落整段混入本条，应移至格助词章节

### 第49条
- **例句2**：`銀行へもデパートへ行きました。【2007年真题】银行和商场都没去。` → 译文与例句不符，应为 `银行和商场都去了。`

### 第54条
- **例句1**：`図書館で3時間勉強しました。でも、うちではいませんでした。` → 应为 `うちではしませんでした`（「いません」误）
- **例句2**：`父に電話をしました。でも、友だちにはませんでした。` → 应为 `友だちにはしませんでした`
- **例句3**：`あ美術館はいつでも人がたくさんいます。` → 应为 `あの美術館は`（缺「の」）

### 第55条
- **例句1**：`玄関のベルが鳴ったけど今頃誰だろ。` → 应为 `誰だろう`（缺「う」）
- **例句2**：`顔色が悪けどどうした。` → 应为 `顔色が悪いけどどうした。`（缺「い」）
- **例句3**：`友だちとの約束を守りたいしたいけど` → 应为 `守りたいけど`（重复「したい」）
- **注意**：`「けど/けど/けど」` → 应为 `「けど/けども/けれど」`

### 第56条
- **例句1**：`飛行機はスピードスピードが速いですです。しかししかし、値ね段が高いですです。` → 严重重复乱码，应为 `飛行機はスピードが速いです。しかし、値段が高いです。`
- **例句2**：`この部屋へはきれきいですです。しかししかし、ちょっちょっと狭いですです。` → 应为 `この部屋はきれいです。しかし、ちょっと狭いです。`
- **例句3**：`この仕事は忙しいです。しかししかし、面白おもしろいですです。` → 应为 `この仕事は忙しいです。しかし、面白いです。`

### 第57条
- **例句1**：`今日きょうはいい天気だから、洗せん濯しましょう。` → 应为 `今日はいい天気だから、洗濯しましょう。`
- **例句2**：`忙しいから、ご飯ごはんを食べる食べる時間がありませんありません。` → 应为 `忙しいから、ご飯を食べる時間がありません。`
- **例句3**：`電車が止まりました。雪ゆきがたくさん降ったからだ。` → 应为 `雪がたくさん降ったからだ。`

### 第58条
- **例句1**：`主人が今出張中ので、うちうちにはいません。` → 应为 `主人が今出張中なので、うちにはいません。`（缺「な」）
- **例句2**：`今度の試験がとても難しかったので、合ご格しませんでした。` → 应为 `合格しませんでした。`

### 第61条
- **例句2**：`東京は人が多く、それに物价も高いので、住みにくいです。` → 「物价」应为「物価」

### 第65条
- **例句1**：`医師「川田さん、晩ご飯を食べ過ぎませんでしたか。」` → 应为 `食べ過ぎたんじゃないですか` 或类似，原文语法不通

### 第67条
- **例句2**：`今9時10分まえです。` → 应为 `今9時10分前です。`（汉字）

### 第69条
- **补充**：`運転ちゅう営業ちゅうお話ちゅう会議ちゅう検討ちゅう仕事ちゅう事情ちゅう受験ちゅう出張ちゅう食事ちゅう調査ちゅう電話ちゅう病気ちゅう勉強ちゅう休みちゅう～月ちゅう午前ちゅう今月ちゅう水ちゅう` → 排版混乱，应加分隔
- **补充**：`家じゅう教室じゅう学校じゅう世界じゅうパートじゅう部屋じゅう町じゅう店じゅう村じゅう一か月じゅう一年じゅう今月じゅう今週じゅう半年じゅう一晩じゅう年じゅう` → 同上

### 第73条
- **例句2**：`あまり慌えると失敗するよ。` → 应为 `あまり慌てると失敗するよ。`（缺「て」）

### 第82条
- **接续**：`名词＋ください` → 应为 `名词＋を＋ください`

### 第83条
- **例句1**：`高いですね。もっと安くしてください。` → 与条目「～てください/ないでください」的否定形式无关，但例句本身无误

### 第88条
- **例句1**：`1 昔から日本へ来たいです。【2008年真题】以后想再来日本。` → 译文与例句不符，应为 `以前就想来日本。`

### 第91条
- **例句1**：`すみませんが、少し静かにしてください。` → 与条目「～にする/くする」相符，但例句与第32条重复

### 第92条
- **例句1**：`寿司が好きになりました。` → 无误
- **例句2**：`大学の友たちは、英語の先生になりました。` → 应为 `友だち`

### 第94条
- **注意**：`「～てある”表示动作完成后形成的某种状态。` → 引号不匹配，应为 `「～てある」`

### 第95条
- **例句3**：`牛乳は全部飲みました。もうありません。` → 无误

### 第97条
- **接续**：`动词普通形/い形容词普通形な形容词词干+な/名词+の}～ほうが～动词「ない形」+ない` → 格式混乱

### 第100条
- **接续**：`动词普通形/い形容词普通形な形容词词干+な名词+の}+ 場合` → 格式混乱

### 第103条
- **例句1**：`ペンのほかに、なに何か必要なものがありますか。` → 应为 `何か必要なものがありますか。`（注音残留）
- **例句2**：`ピアノのほかには、ひギターも弾けますよ。` → 应为 `ギターも弾けますよ。`

### 第105条
- **例句1**：`クラスで王いちばんに背が高い人です。` → 应为 `クラスで王さんがいちばん背が高いです。` 或类似，原文语法不通
- **例句2**：`日本で富士山がいちばんに有名な山です。` → 应为 `いちばん有名な山です。`（多「に」）
- **例句3**：`学校で上田先生がいちばんに優しいです。` → 同上

### 第106-133条
- 全部寒暄语条目格式统一，**例句**均为 `1. ありがとうございます。` 等，与**释义**完全重复，无实质内容问题，但建议补充使用场景说明。

## N4

### 第1条
- **例句2**：`田中さんは遅刻をしないと言ったのに、また遅刻をした。` → 无误

### 第5条
- **接续**：`动词「ない形」/い形容词词干＋くな形容词词干＋で名词＋で{ +なければならない/なければいけない` → 格式混乱，应为 `动词「ない形」/い形容词词干＋く/な形容词词干＋で/名词＋で＋なければならない/なければいけない`

### 第6条
- **接续**：`动词「ない形」/い形容词词干＋くな形容词词干＋で名词＋で} ＋なくてもいい` → 同上格式混乱

### 第7条
- **接续**：`动词「ない形」/い形容词词干＋くな形容词词干＋で名词＋で} ＋なくてはならない/なくてははいけない` → 格式混乱，且 `なくてははいけない` 应为 `なくてはいけない`

### 第8条
- **接续**：`动词「ます形」い形容词词干な形容词词干} ＋すぎる` → 格式混乱

### 第11条
- **例句2**：`このペンは書きやすいですね。` → 无误

### 第19条
- **接续**：`动词辞书形/名词＋ばかり` → 无误

### 第22条
- **接续**：`动词辞书形/名词＋までに` → 无误

### 第23条
- **例句1**：`暇だからゲームでもしょう。` → 应为 `ゲームでもしよう。`（缺「う」）

### 第28条
- **接续**：`名词／na形容词词干＋だったりi形容词词干＋かったり动词「た形」＋り` → 格式混乱

### 第29条
- **接续**：`动词普通形／i形容词普通形na形容词词干＋だ名词＋だ` → 格式混乱

### 第32条
- **接续**：`动词「た形」/动词「ない形」＋ないい形容词辞书形/な形容词词干＋な名词＋の` → 格式混乱

### 第35条
- **接续**：`动词普通形/い形容词普通形な形容词词干名词}～かもしれない` → 格式混乱

### 第37条
- **例句2**：`旅行に行ってたつもりで、そのお金をためめておいた。` → 应为 `ためておいた`（多「め」）

### 第38条
- **接续**：`动词普通形/い形容词普通形な形容词词干＋な名词＋の}～はずだ 动词普通形/い形容词普通形な形容词词干+な名词+の→ +ははずがない` → 格式混乱

### 第39条
- **接续**：`动词「た形」＋たらい形容词词干＋かったな形容词词干/名词＋だった` → 格式混乱

### 第40条
- **接续**：`动词普通形＋(の/ん)＋ならい形容词普通形＋(の/ん)な形容词词干/名词` → 格式混乱

### 第41条
- **例句1**：`このケーキは冷たくなければ、おいしくありません。` → 无误

### 第42条
- **接续**：`动词普通形/い形容词普通形な形容词词干＋だ名词＋だ＋と` → 格式混乱
- **解析**：`拆解：并列助词。①「名＋と＋名」表事物并列。②语感来源：表「和…、跟…」。③位置：句中连接名词。` → **错误**：本条是「～と」表条件，解析却写成了并列助词，与N5第46条混淆

### 第44条
- **例句1**：`加藤「明日はサッカーの試合です。もし雨も降っても試合をします。` → 应为 `もし雨が降っても`（「も」应为「が」）

### 第46条
- **接续**：`动词普通形/い形容词普通形＋ためな形容词词干＋な名词＋の 名词＋の/动词辞书形＋ために` → 格式混乱

### 第47条
- **接续**：`动词辞书形/动词「ない形」＋ない/动词可能形＋よう` → 格式混乱

### 第50条
- **接续**：`Ⅰ 类动词 把词尾改为「お段」假名Ⅱ 类动词 「ない形」+よⅢ 类动词 する→しょ；来る→来yo}+うとする` → 格式混乱

### 第52条
- **接续**：`动词普通形/い形容词辞书形な形容词词干+な名词+の}+かわりに` → 格式混乱

### 第53条
- **接续**：`ちっとも＋い形容词词干＋く/动词「ない形」＋ない` → 格式混乱

### 第55条
- **接续**：`动词「ない形」＋ないで` → 无误

### 第56条
- **接续**：`动词「ない形」/い形容词词干＋くな形容词词干＋で名词＋で} ＋なくて` → 格式混乱

### 第62条
- **例句1**：`まだこのマンガを読んだことがあります。` → 应为 `読んだことがありません。` 或 `読んだことはありません。`（肯定与「まだ」矛盾）
- **例句2**：`日本の音楽はまだ聞いたことがあります。` → 同上，应为 `聞いたことがありません。`
- **注意**：`「～ことがある」前面接动词过去式的时候，表示曾经做过某事。` → 无误

### 第63条
- **注意**：`其否定形式为「～ことができいない」。` → 应为 `「～ことができない」`

### 第64条
- **例句2**：`A「草色というはどんな色ですか。」` → 应为 `草色というのはどんな色ですか。`（缺「の」）
- **例句3**：`B「今わたしが着ているシャツのような、こんな色です。」` → 无误

### 第65条
- **接续**：`动词意志形＋と思う` → 无误

### 第66条
- **例句1**：`A「山川さんの誕生日にこの財布をあげるつもりです。」` → 无误
- **注意**：`「～あげる」表示自己或己方的人给别人东西，主语是自己或己方的人，通常可以省略。` → 无误

### 第67条
- **例句1**：`A「けしゴム持ってる？」` → 无误

### 第68条
- **例句3**：`上司から指示をいただきました。` → 无误

### 第70条
- **例句1**：`木田さんは、わたしに本をきだくれました。` → 应为 `本をくれました。`（注音残留乱码）
- **例句3**：`おじは万年筆まんをひつました。` → 应为 `おじは万年筆をくれました。`（严重乱码）

### 第71条
- **例句1**：`そちらの方がわたしの荷物にんを持ってくださいました。` → 应为 `荷物を持ってくださいました。`
- **例句2**：`友たちが掃除をて手伝ってくれた。` → 应为 `友だちが掃除を手伝ってくれた。`

### 第72条
- **释义**：`「～やる」表示自己把东西给地位比自己低的人或者是动植物,主语是自己。` → 无误
- **例句**：全部无误

### 第73条
- **例句3**：`子どもたちに小遣いを配ってやった。` → 无误

### 第74条
- **例句1**：`そのたんごのよかたおし読み方を教えてちょうだい。` → 严重乱码，应为 `その単語の読み方を教えてちょうだい。`
- **例句2**：`おかし子をか買ってちょうだい。` → 应为 `お菓子を買ってちょうだい。`
- **例句3**：`そのしんぶんと新聞を取ってちょうだい。` → 应为 `その新聞を取ってちょうだい。`

### 第75条
- **接续**：`Ⅰ 类动词「ない形」+せてください/せないでくださいⅡ 类动词「ない形」+らせてください/させないでくださいⅢ 类动词：(～)する→(～)させてください来るこ→来こさせてください/させないでください` → 格式混乱
- **例句3**：`兄怪我したので、あに明日はアルバイトをやすませてください。` → 应为 `兄が怪我したので、明日はアルバイトを休ませてください。`

### 第77条
- **注意**：`「見える/お見えになる」是「来る」的特殊敬语格式。` → 无误

### 第82条
- **例句1**：`中川さんが描いた絵をご覧になりましたか。` → 无误

### 第86条
- **接续**：`お + Ⅰ类动词、Ⅱ类动词「ます形」 + なさるご + Ⅲ类动词词干 + なさる` → 格式混乱
- **例句1**：`部長は新企画についてお話しいたしました。` → **错误**：例句用了「お～いたしました」而非「お～なさる」，与条目不符

### 第87条
- **接续**：`お + Ⅰ类动词、Ⅱ类动词「ます形」+ になるご + Ⅲ类动词词干 + になる` → 格式混乱

### 第88条
- **接续**：`お + Ⅰ类动词、Ⅱ类动词「ます形」+ くださいご + Ⅲ类动词词干 + ください` → 格式混乱
- **例句1**：`では、お元気で。ご両親にもどうぞようしくお伝えください。` → 应为 `よろしく`

### 第89条
- **接续**：`Ⅰ类动词「ない形」+ れるⅡ类动词「ない形」+ られるⅢ类动词 （～）する → （～）される；来る → 来られる` → 格式混乱

### 第91条
- **注意**：`「いる」是「いる」的自谦表达。` → 应为 `「おる」是「いる」的自谦表达。`（条目名为「いる」但内容说的是「おる」）

### 第95条
- **释义**：`「存じています」意为“知道……”。` → 条目名为「存じている」，释义却写「存じています」，不统一

### 第103条
- **例句1**：`先生は毎日お魚をあげますか。` → **错误**：应为 `お魚を召し上がりますか。`（「あがる」在此条为尊他语，但「あげます」是他动词“给”的意思，混淆）
- **例句2**：`新しい課長はどのくらいお酒をあげますか。` → 同上，应为 `お酒を召し上がりますか。`
- **注意**：`「あがる」是「食べる」「飲む」的尊他语。` → 无误，但例句错误

### 第106条
- **释义**：`「～ておく」是「～ている」的自谦表达。` → **错误**：应为 `「～ておる」是「～ている」的自谦表达。`（条目名为「～ておく」但内容说的是「～ておる」）
- **例句1**：`荷物はわたしがお持ちしております。` → 应为 `お持ちしております` 无误，但例句与「～ておく」无关
- **例句2**：`今、上海に住しております。` → 应为 `住んでおります`
- **例句3**：`ただいま、外出しております。` → 无误

## N3

### 第1条
- **接续**：`动词普通形/い形容词普通形な形容词词干＋な名词＋の | } | あいだ＋ 間` → 格式混乱

### 第2条
- **接续**：同上格式混乱

### 第3条
- **接续**：`动词「ます形」＋あがる` → 无误

### 第4条
- **接续**：`动词「ます形」＋いい/よい` → 无误

- **接续**：`名＋をよそに` → 无误

### 第197条
- **接续**：`動ない形＋んがため(に)/んがための(する→せんがため)` → 无误

### 第198条
- **接续**：`文の普通形＋んじゃない` → 无误
- **例句1**：`このソファスペースとるし、デザインもいまいちなんだから、最初から買うんじゃない。` → 应为 `このソファ、スペースとるし`
- **例句3**：`こんなことになるなんて思わなかった。彼女に話すんじゃない。` → 应为 `話さなければよかった` 或 `話すんじゃなかった`

### 第199条
- **接续**：`動普通形/イ形名/ナ形語幹＋な | ～んだって/んですって` → 格式混乱

### 第200条
- **接续**：`動ない形＋んばかりに/んばかりの/んばかりだ(する→せんばかり)` → 无误
- **例句3**：`彼女は泣かんばかりに、「元気でね」と言いながら手を振った。` → 无误
- **注意**：末尾混入考试结构说明文字，与语法条目无关
